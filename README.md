# 🎓 College Event Feedback Analysis 
**Future Interns – Data Science & Analytics Internship (Task 3)**

## 📌 Project Overview
This project focuses on analyzing student feedback collected after college events to understand satisfaction levels, identify common sentiments, and suggest actionable improvements. The analysis combines survey data exploration with basic Natural Language Processing (NLP) techniques.

---

## 🎯 Objectives
- Analyze student ratings for different college events  
- Perform sentiment analysis on textual feedback  
- Identify satisfaction trends and problem areas  
- Provide data-driven recommendations for event improvement  

---

## 🛠 Tools & Technologies Used
- **Python**
- **Pandas** – data cleaning & manipulation  
- **Matplotlib & Seaborn** – data visualization  
- **TextBlob / VADER** – sentiment analysis  
- **Excel** – survey data storage  
- **Google Colab / Jupyter Notebook**

---

## 📂 Dataset Description
The dataset contains feedback collected from students through a survey.

### Columns:
| Column Name | Description |
|------------|------------|
| Student_ID | Unique identifier for students |
| Event_Name | Name of the college event |
| Rating (1–5) | Satisfaction rating |
| Feedback_Text | Student feedback |
| Would_Recommend | Yes / No response |

---

## 📊 Analysis Performed
- Descriptive statistics of event ratings  
- Rating comparison across events  
- Sentiment classification (Positive, Negative, Neutral)  
- Visualization of satisfaction trends  
- Identification of improvement areas  

---

## 📈 Key Insights
- Events with higher ratings generally received positive sentiment feedback  
- Common issues identified include timing, interaction level, and organization  
- Practical sessions and hackathons received the highest satisfaction  

---

## 💡 Recommendations
- Improve event scheduling and time management  
- Increase audience interaction in seminars and workshops  
- Collect feedback digitally for faster analysis
